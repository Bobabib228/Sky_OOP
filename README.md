# Проект по ООП на Python
## Цель проекта
Проект по ООП на Python, реализующий классы Product и Category с подсчетом количества категорий и товаров."

## Что нового
1) Были созданы 2 класса **Pduct** и **Category**
2) Были написаны тесты для этих классов

### Запуск тестов
Для запуска тестов введите команду `pytest`
Отчет о покрытии тестами лежит в файле **index.html**
